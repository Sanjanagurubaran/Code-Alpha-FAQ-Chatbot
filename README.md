# FAQ Chatbot 🤖

An AI-powered FAQ Chatbot built using **Flask, HTML, CSS, JavaScript, and Machine Learning (NLP)**.
The chatbot answers user queries intelligently using **TF-IDF Vectorization** and **Cosine Similarity**.

---

## 🚀 Features

* 💬 Interactive chatbot interface
* 🧠 NLP-based question matching
* ⚡ Fast response system
* 🎨 Modern responsive UI
* 📂 CSV-based FAQ dataset
* 🔍 TF-IDF vectorization
* 🤝 Cosine similarity matching
* 📱 Mobile-friendly design

# 🧠 How It Works

1. User enters a question.
2. The chatbot converts text into vectors using TF-IDF.
3. Cosine similarity compares the user question with stored FAQ questions.
4. The most similar answer is returned.
